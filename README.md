# 星笺 · 联系人管理

> EE308FZ Software Engineering · Extreme Programming Address Book

一个无需后端、打开即用的浏览器地址簿示例，覆盖作业要求：收藏联系人、多种联系方式、Excel 导入/导出。

## 运行

直接双击 `index.html`，或在本目录启动静态服务器：

```bash
python -m http.server 5173
```

然后访问 http://localhost:5173。首次打开不需要安装依赖；Excel 功能使用 SheetJS CDN。

## 功能说明

- **收藏**：联系人卡片右上角星标；左侧“我的收藏”可筛选。
- **多种联系方式**：一个联系人可添加手机、邮箱、微信、电话、地址及自定义类型。
- **Excel**：导出生成 `星笺联系人.xlsx`，每位联系人一行；导入支持同样的列：姓名、公司、职位、标签、收藏、手机、邮箱、微信、其他联系方式、备注。
- **持久化**：数据存储在浏览器 localStorage，不上传个人信息。

## 代码规范

- JavaScript 使用 `const/let`，函数职责单一，命名采用 camelCase。
- CSS 使用语义化 class，颜色与间距通过 `:root` 变量统一管理。
- 不使用 `innerHTML` 写入用户字段前统一经过 `esc()` 转义。
